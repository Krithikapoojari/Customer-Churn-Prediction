# Customer Churn Prediction and Analysis

## Project Overview

This project predicts customer churn using Machine Learning and presents the insights through an interactive Power BI dashboard. The objective is to identify customers who are likely to leave the service and analyze the key factors influencing churn.

---

## Dataset

- **Dataset:** Telco Customer Churn Dataset
- **Records:** 1,407 customers
- **Target Variable:** Predicted_Churn

---

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Power BI

---

## Machine Learning Workflow

- Data Cleaning and Preprocessing
- Feature Encoding
- Train-Test Split
- Random Forest Classifier
- Customer Churn Prediction
- Model Evaluation using Confusion Matrix
- Feature Importance Analysis

---

## Power BI Dashboard

The dashboard provides:

- Total Predictions
- Predicted Churn Customers
- Predicted Churn Rate
- Average Monthly Charges
- Customer Churn Distribution
- Churn by Gender
- Churn by Contract Type
- Churn by Internet Service
- Interactive Filters
